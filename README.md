# Afnek — Hotel Booking Platform

Afnek is a hotel booking web application built with Next.js. The project focuses on providing users with a convenient way to explore hotel accommodations and interact with a hotel booking platform.

## 🔗 Project Repository

Explore the source code on GitHub:

[**Afnek — Next.js Hotel Booking Platform**](https://github.com/mamoun97/afnek-next)

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm, yarn, pnpm, or Bun
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/mamoun97/afnek-next.git
```

Navigate to the project directory:

```bash
cd afnek-next
```

Install the dependencies:

```bash
npm install
```

### Run the Development Server

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to access the application.

The page will automatically update as you modify the source code.
